# EduCore — Enterprise Learning Management System

## Description
EduCore is a scalable Learning Management System (LMS), inspired by 
platforms like Udemy/Coursera, that allows instructors to create and 
manage courses while students browse, enroll, and track their learning 
progress.

## Track
Fullstack

## Tech Stack
- Frontend: React (Vite) + Tailwind CSS
- Backend: Node.js + Express.js
- Database: MongoDB (Mongoose)
- Auth: JWT-based authentication
- Deployment: Vercel (frontend) + Render/Railway (backend)

## Core Features (Priority Order)

### Must-Have (MVP)
1. User Authentication (Student / Instructor roles)
2. Course Catalog (browse, search, filter courses)
3. Student Dashboard (enrolled courses, progress)
4. Instructor Portal (create/edit courses, upload lessons)
5. Course Details Page (syllabus, lessons list)
6. Enrollment System (enroll/unenroll in a course)

### Should-Have
7. Progress Tracking (mark lessons complete, % progress bar)
8. Media Player UI (video lesson playback)
9. Search & Filter (by category, level, instructor)

### Nice-to-Have (later sprints)
10. Ratings & Reviews
11. Certificates on completion
12. AI-based course recommendations (Sprint 16)
