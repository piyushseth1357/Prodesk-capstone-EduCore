# AI Prompts Used — EduCore

I used AI mainly to get unstuck on things I wasn't sure about, 
not to generate the whole plan for me. Here's roughly what I asked:

1. "What collections should an LMS database have?"
   → Got a starting point, then adjusted it myself to fit EduCore's 
     specific features (removed some I didn't need, kept 4 main ones).

2. "How do I make a progress bar look right in Figma without a plugin?"
   → I was stuck on this in the wireframe, AI explained the 
     overlapping rectangles trick which I then used.

3. "How to write dbdiagram.io syntax for table relationships"
   → I didn't know the exact syntax for this tool, so I asked and 
     then wrote my own table names/fields based on my actual schema.

Most of my README content, feature prioritization, and design 
decisions were things I worked out myself — I used AI more like a 
quick reference/troubleshooting tool than as a project generator.
